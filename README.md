# Electricista Sur · Dante

Sitio estático original de Electricista Sur, independiente de `electricista-sur-preview` y de `demo-electricista`. Implementado con HTML, CSS y JavaScript nativos, sin paquetes ni backend.

## Contenido

- `index.html` — landing completa, metadatos SEO/social, datos estructurados y marcador de revisión no visible.
- `styles.css` — sistema visual propio, accesibilidad y layouts responsive.
- `script.js` — menú accesible y año del pie; el contacto es un enlace directo a WhatsApp, nunca envía mensajes automáticamente.
- `assets/` — logo y fotografías locales autorizadas de la referencia Electricista Sur; favicon SVG original.
- `robots.txt`, `sitemap.xml` — rastreo e indexación para GitHub Pages.

Las fotografías se reutilizan desde los activos locales de `electricista-sur-preview`; no se cargan imágenes remotas. El teléfono, correo, servicios, Quilmes, la matrícula, la experiencia y los testimonios se basan en el contenido público de referencia revisado para este sitio. Se excluyen claims numéricos de métricas, disponibilidad/tiempos de respuesta, horarios, el formulario y la página de contacto de la referencia.

## Publicación

Repositorio independiente `TuWebEnTresDias/electricista-sur`, servido desde la raíz de `main` con GitHub Pages.
